# Benchmark R1 campaign

This is a short historical summary of the earlier R1-001 campaign. It is separate from the later TASK-0019 2×2 experiment.

R1 evaluated four sequential Haiku configurations (V0–V3) on a 24-question aggregate benchmark: 12 TRAIN, 6 TEST, and 6 HOLDOUT questions, with two repetitions per question and candidate. TEST was sealed after development and all four configurations were scored on it. Every configuration received 0/24 deterministic acceptances on TEST, so the predeclared decision selected no candidate and HOLDOUT was not opened.

R1 is evidence about this small campaign and its release controls. It is not a result for TASK-0019 and does not support a general model-quality claim. The [R1 result summary](../publication/r1_public_result_summary.md) contains its public outcome; the [prospective protocol](../methodology/protocol.md) describes the wider lifecycle.

The original dataset, hidden questions, evaluator keys, and raw cloud evidence remain private. The reference implementation's public offline reproduction uses only the synthetic fixture.
